# Recipe AI Summary Notice for Firefox 1.3.0

This release introduces WordPress-native settings cards, controls and a live wording preview, with an ordinary Settings API form available when JavaScript is disabled. The reader notice now has refined typography, spacing, rounded surfaces, hover and focus styling. Reader choices and storage behavior remain unchanged.

Built by And/or Labs Inc. Original idea: [Don Marti](https://www.linkedin.com/posts/dmarti_should-recipe-sites-start-blocking-firefox-share-7511824622989008896-pGED/). See the README for sourced Mozilla news context and current screenshots.

Download `recipe-ai-summary-notice-1.3.0.zip` below, then use Plugins > Add New Plugin > Upload Plugin. Upgrading from the old Recipe Warning directory requires deactivating the old copy first; settings and recipe flags are retained.

27 focused frontend checks passed across Chromium, Firefox and WebKit. Admin saving, live preview, responsive layout, accessibility, and no-JavaScript fallback were checked separately. The 57 PHP release assertions and WordPress Plugin Check passed. See TESTING.md for the broader baseline and test boundaries.

The plugin is a dismissible notice. It cannot disable AI summaries or verify browser settings. WordPress.org review remains separate from this GitHub release.
