# Recipe AI Summary Notice for Firefox 1.2.0

The plugin and repository now have a descriptive name: recipe AI summaries, a reader notice, and Firefox mobile targeting. Built by And/or Labs Inc.; original idea credited to [Don Marti](https://www.linkedin.com/posts/dmarti_should-recipe-sites-start-blocking-firefox-share-7511824622989008896-pGED/).

Download `recipe-ai-summary-notice-1.2.0.zip` and upload it through WordPress Plugins > Add New Plugin. GitHub source archives are for development.

When upgrading from Recipe Warning 1.1.0, deactivate the old plugin first. The new plugin retains the existing settings, manual recipe flags, and browser preference storage keys. Do not activate both copies together.

This release updates the plugin directory, main file, translation domain, and public documentation. Reader behavior remains the same: continue to the original recipe, copy its URL, or remember a reader’s confirmation that summaries are disabled for seven days. The plugin cannot disable or verify Firefox summaries.

The repository now includes an actual mobile preview, a clear download link, sourced Mozilla news context, attribution, and a submission-guidelines audit. WordPress.org approval is not claimed.

Validation: installable archive matched source and installed files, 57 PHP release checks passed, WordPress Plugin Check found no errors, and focused browser/content checks passed. See TESTING.md and docs/SUBMISSION-AUDIT.md for scope and submission requirements.
